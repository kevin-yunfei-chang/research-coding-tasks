# PREDOC 2025 — Section 3: Pollution and Mortality

This independent RStudio project completes **Questions 3-1 to 3-4**, estimates three county-date fixed-effects regressions, and lets **R itself** produce a publication-style three-line LaTeX regression table from the fitted models. Real coefficient estimates are **not hard-coded** in any output.


Input path, resolved relative to the Section 3 directory:

`../2-1.Section 01/Output/1-5/1-5_county_day_panel.rds`

The script **does not** load any other input file or modify Section 1 results. Its working directory may be either the `2-3.Section 03` RStudio project or the parent project directory.

## 2. Run the script

1. Move the complete `2-3.Section 03` folder into your existing Booth PREDOC project folder.
2. Double-click `2-3.Section 03.Rproj` and open `03_section3.R` in RStudio.
3. Highlight and run the **SETUP** block, then run `3-1`, `3-2`, `3-3`, `3-4`, and **FINAL TABLE**, in that order (macOS: **Command + Return**).
4. To rerun all modules after a clean RStudio restart:

```r
source("03_section3.R", echo = TRUE)
```

Or from the parent project working directory:

```r
source("2-3.Section 03/03_section3.R", echo = TRUE)
```

**Dependencies:** R and the CRAN package [`fixest`](https://lrberge.github.io/fixest/reference/feols.html) (automatically installed on the first run if absent). For PDF compilation, a LaTeX distribution containing **pdflatex** and **booktabs** (e.g. MacTeX) must be present. ZIP creation uses the macOS `zip` command. The `.tex` and `.csv` files are produced regardless of whether LaTeX is installed.

## 3. Regression specification

The unit of observation is **county–day**. Mortality is synthetic and is **not** a real observed death count.

### 3-1 — Baseline two-way fixed effects

\[
Mortality_{it} = \beta_1 AQI_{it} + \alpha_i + \delta_t + \varepsilon_{it}.
\]

The reported coefficient is the association with a **one-unit higher AQI**, controlling for persistent county differences and shocks common to all counties on a given calendar day.

### 3-2 — Previous-day AQI

\[
Mortality_{it} = \beta_1 AQI_{it} + \beta_2 AQI_{i,t-1}
  + \alpha_i + \delta_t + \varepsilon_{it}.
\]

The lag is explicitly constructed using the **previous calendar day in the same county**, never the previous available row. An absent day is treated as a missing lag, reducing Model (2)'s estimation sample.

### 3-3 — CBSA interaction

\[
Mortality_{it} = \beta_1 AQI_{it}
  + \beta_3 (AQI_{it}\times CBSA_i)
  + \alpha_i + \delta_t + \varepsilon_{it}.
\]

`CBSA_i = 1` when a county's `cbsacode` is present, and `0` otherwise. The code requires the CBSA indicator to be constant within each county. The **non-CBSA AQI slope** is `β1`; the **CBSA AQI slope** is `β1 + β3`; `β3` is their difference. A clustered delta-method SE for the CBSA slope is exported separately.

### 3-4 — Collinearity explanation

A county's CBSA status is time-invariant. Therefore, the **CBSA main effect is collinear with county fixed effects** and cannot be separately estimated when those fixed effects are present. The script estimates a diagnostic version of Model (3) with the indicator included; the collinear term is automatically omitted. The interaction remains because AQI varies over time.

## 4. Inference and sample rules

- OLS models use the [`fixest::feols()`](https://lrberge.github.io/fixest/reference/feols.html) estimator with **county and calendar-date fixed effects**.
- Reported standard errors are **clustered by county**, with `fixest` default small-sample correction settings.
- Only rows with finite values for required regressors/outcome enter each model; the lag specification may have a different sample size.
- Missing `cbsacode` is interpreted as not in a CBSA, subject to the source data dictionary. There must be both CBSA and non-CBSA counties in the estimation sample to estimate differential slopes.
- The program checks for duplicate county-date keys and conflicting CBSA status assignments.
- Coefficients are **associations, not causal estimates**. Synthetic mortality data must not be used for health policy conclusions.

| `Output/3-2/` | `3-2_model.rds`, `3-2_coefficients.csv`, `3-2_model_statistics.csv`, `3-2_regression_summary.txt`, `3-2_lag_audit.csv`, `3-2_interpretation.md` |
| `Output/3-3/` | `3-3_model.rds`, `3-3_coefficients.csv`, `3-3_model_statistics.csv`, `3-3_regression_summary.txt`, `3-3_cbsa_marginal_slopes.csv`, `3-3_cbsa_coverage.csv`, `3-3_interpretation.md` |

| `Output/Regression_Tables/` | Three-model `.tex` table, compilable `.tex` wrapper, coefficient CSV, and (when tools are available) the **automatically compiled real PDF** and **ZIP of LaTeX sources**. A compilation log/status file is also written. |

The primary LaTeX files are:

- `3_regression_table.tex` — table body, suitable for `\input{}` in another LaTeX document;
- `3_regression_table_main.tex` — standalone document for compilation;
- `3_regression_table_main.pdf` — compiled automatically when `pdflatex` is available;
- `3_regression_latex_sources.zip` — created automatically using `zip` if installed;
- `3_regression_table_coefficients.csv` — real estimated coefficient values and county-clustered standard errors.

### Main table layout

The **three columns** are: **(1) Baseline TWFE**, **(2) Current + Lagged AQI**, and **(3) AQI × CBSA**. Rows display current AQI, yesterday's AQI, the AQI–CBSA interaction, county FE, date FE, observations, county clusters, overall R² and within R². Standard errors appear beneath coefficients with conventional significance stars. The LaTeX body uses `booktabs` `\toprule`, `\midrule`, and `\bottomrule`, no vertical rules, and explanatory footnotes.

**A PDF cannot be created by this script on a machine without a TeX distribution.** The code writes the LaTeX source and an explicit status note instead; it does not fabricate coefficient estimates or claim successful compilation.

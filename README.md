This repository contains a collection of independent
research coding tasks, replication exercises, and
technical assessments related to economics and
applied empirical research.

- Data cleaning and management
- Large-scale data processing
- Econometric analysis
- Statistical modeling
- Data visualization
- Reproducible research
- Economic interpretation

Programming languages include R, Python, and Stata.

## Repository Policy

This repository is intended to demonstrate research
programming and empirical analysis skills.

Only the following materials are included:

- Source code
- Regression results
- Figures and tables
- Written interpretations
- Project documentation

Original datasets, confidential materials,
and observation-level intermediate data
are not included.

Each project provides its own README with
additional details on the research task,
methods, and reproducibility.
